# 民生咨询代表性补充

识别规划咨询中未被充分覆盖的人群，并组织可审计的补充触达。

## 业务事实

- 规划覆盖住房、医疗和青年发展
- 公众咨询收到超过一万七千份意见或建议
- 住房与医疗目标具有明确的跨年度数量

## 协作角色

- 规划统筹部门
- 执行部门
- 公众咨询团队
- 审计与发布人员

## 目录说明

- `contracts/domain.schema.json` 定义共享资料的字段与基本约束。
- `fixtures/context.json` 提供不含真实个人信息的公开样例。
- 源码目录包含资料读取与基础校验逻辑，便于后续服务统一接入。

## 本地检查

运行项目自带测试可确认样例能够读取，领域标识、版本、参与者和记录结构完整。样例中不包含账号、密钥或连接凭据。
