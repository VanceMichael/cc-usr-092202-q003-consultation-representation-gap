# 民生咨询代表性补充

识别五年规划咨询中未被充分覆盖的人群，并组织可审计的补充触达。
核心立场：**提交量不等于覆盖**；被邀请或到场不代表赞成任何政策。

## 业务事实

- 规划覆盖住房、医疗和青年发展
- 公众咨询收到超过一万七千份意见或建议
- 住房与医疗目标具有明确的跨年度数量
- 熟悉线上渠道的团体会反复发声；轮候公屋住户、长期照护者、部分青年可能从未进入样本

## 计数铁律（系统强制，而非人工约定）

- 统计单位永远是**去重后的声音**，不是原始提交量
- 同一人经任何渠道多次提交 → 合并为 1 个声音
- 同一团体反复发声 → 合并为 1 个声音
- 联署书每份计 1 个声音；**签名人数只登记、绝不相加**
- 标记为 `duplicate_of` 的重复投递并入原件，贡献 0 个新声音
- 活动签到只记录出席过程，**绝不计入意见声音数**
- 人群/年龄段/地区只来自本人**自愿披露的结构化选项**；字段白名单从结构上拒绝任何 `inferred_*`、`stance` 类字段，不读取意见文字、不推断敏感身份
- 联络授权与分析授权可**分别撤回**；撤回事件永久留痕，撤回后的声音不进入代表性统计

## 模块

| 文件 | 职责 |
| --- | --- |
| `src/intake.js` | 收件/签到/基准资料的白名单结构校验与受控词表（渠道、十八区、议题、自披露人群） |
| `src/voices.js` | 声音去重与总数对账（件数 − 重复投递 − 重复提交 = 声音数） |
| `src/coverage.js` | 按渠道/地区/议题/自披露人群/年龄段及人群×地区交叉细格统计；对照部门人口基准输出缺口地图（missing / underrepresented / thin_evidence / adequate） |
| `src/outreach.js` | 社区访谈、无障碍场次、翻译资源、定向邀请的事件溯源日志；席位预留与冲突、候补顺位、递补、临时退出、缺席、翻译/无障碍待办、授权撤回全部不可删除 |
| `src/attribution.js` | 逐场核对每个到场者属于哪一类：真正填补缺口的新声音 / 基线已存在 / 未对准缺口 / 只增总数 / 授权撤回 / 仅到场无意见 / 获邀未参与 |
| `src/staff.js` | 工作人员内部面板：逐场结论、缺口状态迁移、待办与异常（含精确计数，禁止对外） |
| `src/publish.js` | 公开方法说明：K-匿名门槛以下细格一律显示 `< K`，其余给固定宽度区间；保留计数规则、不确定性、授权与中立声明 |

数据结构上**没有任何字段**记录政策立场或意见内容；`attendance_implies_endorsement: false` 在每场快照中明示。

## 输出的两种视图

- **工作人员视图**：可见精确计数、逐人逐场结果与缺口定位，用于核对每次补充触达是否真的补上了缺少的声音，而不是制造更好看的总数。
- **公开视图**：只呈现达到匿名门槛的范围与不确定性；各表有意不能相加为总数，门槛以下（含 0 与小计数）不可区分，无法反推个人或定位小群体空缺。

## 目录

- `contracts/domain.schema.json` 共享领域资料的字段与基本约束
- `fixtures/context.json` 公开样例（领域骨架）
- `fixtures/consultation.sample.json` 全流程虚构样例（意见、联署、签到、基准、跟进意见），人物均为占位代号
- `scripts/demo.mjs` 端到端演示：收件对账 → 缺口地图 → 三场补充触达（席位冲突/候补递补/退出/缺席/翻译/无障碍/授权撤回）→ 工作人员核对 → 公开方法说明

## 本地检查

```bash
npm test          # 42 项单元测试
node scripts/demo.mjs   # 全流程演示（输出为内部+公开两种视图）
```

样例与测试均为虚构数据，不含账号、密钥、连接凭据或真实个人信息。
