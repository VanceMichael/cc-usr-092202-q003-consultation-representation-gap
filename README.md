# 民生咨询代表性补充

识别规划咨询中未被充分覆盖的人群，并组织可审计的补充触达。

## 业务事实

- 规划覆盖住房、医疗和青年发展
- 公众咨询收到超过一万七千份意见或建议
- 住房与医疗目标具有明确的跨年度数量

## 协作角色

- 规划统筹部门
- 执行部门
- 公众咨询团队
- 审计与发布人员

## 目录说明

- `contracts/domain.schema.json` 定义共享资料的字段与基本约束。
- `fixtures/context.json` 提供不含真实个人信息的公开样例。
- `fixtures/submissions.sample.json` / `fixtures/targets.sample.json` 提供合成的意见记录与覆盖目标样例。
- `src/records.js` 读取并校验共享领域资料。
- `src/coverage.js` 意见覆盖画像与代表性缺口地图。
- `src/outreach.js` 补充触达排程与过程留痕。
- `src/publishing.js` 匿名方法公开与内部核对视图。

## 统计口径

- 只按渠道、地区、关注议题与自愿披露的人群特征统计；不从意见文字推断敏感身份，未披露即计入「未披露」。
- 联署按一份集体意见计算，签名人数不并入总数；同一提交者的重复投递只计一次；活动签到单独呈现，不计入意见数。
- 缺口 = 各维度分段低于目标最低覆盖数的部分；数量为 0 的分段即「从未进入样本」。

## 补充触达

- 场次类型：社区访谈、无障碍场次、翻译资源、定向邀请。
- 席位冲突自动转候补；临时退出释放席位并按序转正；授权撤回后该参与者不计入任何统计、披露特征即不可用，但全部过程事件留痕。
- 被邀请或到场不代表赞成任何政策：携带立场字段的事件会被拒绝。
- 工作人员可逐场核对：到场且授权有效的参与者中，多少是既有意见之外的新声音、落在哪些缺口段上；只做大总数而未填补缺口的场次会被标记 `onlyInflatesTotal`。

## 公开与内部视图

- 公开方法说明只呈现达到匿名门槛的区间与不确定性，小于门槛的格子一律抑制。
- 内部视图保留精确计数与逐场缺口填补核对，仅供工作人员使用，不得原样公开。

## 本地检查

运行项目自带测试可确认样例能够读取，领域标识、版本、参与者和记录结构完整。样例中不包含账号、密钥或连接凭据。
